# Example notes

This folder contains sample notes generated by `extract.py` from real YouTube videos. They show what the tool produces end-to-end without having to run it yourself.

All examples were generated with the default LLM provider (**Gemini 2.5 Flash**) on videos from the [Le SamourAI](https://www.youtube.com/@SamouraiDansant) channel.

Each note follows the 10-section template defined in [`SPECS.md`](../SPECS.md) Bloc 3:
central thesis, inferred chapter breakdown, idea map, key concepts, notable
quotes, open questions, empty personal notes, filtered sources, and the full
timestamped transcript.

LLM outputs are non-deterministic — running `extract.py` on the same video
will produce a similar but not identical note.
